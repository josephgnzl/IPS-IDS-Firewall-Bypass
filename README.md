# IPS-IDS-Firewall-Bypass Técnicas de Evasión Avanzadas

El enfoque es **avanzado y reproducible**: cada técnica incluye la teoría subyacente (por qué funciona), los comandos exactos, el escenario de laboratorio y las limitaciones defensivas. El objetivo no es solo "saltarse" un control, sino entender cómo funcionan los firewalls stateless/stateful, los IDS basados en firmas y los IPS en línea, para poder evadirlos de forma controlada.

## ¿Qué es un firewall?

Un firewall es un control de seguridad que aplica políticas sobre el tráfico de red para determinar qué comunicaciones se permiten, se bloquean o se inspeccionan. Su comportamiento depende de las reglas configuradas, el contexto de la conexión y las capacidades de inspección implementadas.
